# nerdcast-explorer
O Jovem Nerd existe desde 2006 e o NerdCast é um dos podcasts mais antigos e queridos do Brasil — com mais de 2.000 episódios espalhados por dezenas de programas diferentes. Mas quem chega hoje no site pela primeira vez se depara com uma experiência que não acompanhou o crescimento do acervo: sem filtros avançados, sem ordenação flexível, sem como ver todos os episódios de uma vez, e muito menos acompanhar o próprio progresso de escuta. O nerdcast-explorer nasceu dessa frustração. É um acervo não-oficial, construído por fãs para fãs, com o único objetivo de tornar esse universo de conteúdo mais navegável — sem substituir o site do Jovem Nerd, mas complementando o que ele não oferece. Aqui você consegue explorar todos os episódios desde o primeiro NerdCast de abril de 2006, filtrar por programa, tema ou ano, ordenar do jeito que quiser e, principalmente, marcar o que já ouviu. Para o nerd completista que quer zerar o backlog, para quem acabou de descobrir o podcast e não sabe por onde começar, e para quem só quer encontrar aquele episódio de Star Wars que ouviu uma vez e nunca mais achou. O projeto é open-source, os dados são atualizados automaticamente via RSS, e qualquer contribuição é bem-vinda.
